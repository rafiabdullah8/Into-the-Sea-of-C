## ▶️ How to Use

You can browse the folders and open any `.c` file to see the source code.

### Clone the Repository

```bash
git clone https://github.com/rafiabdullah8/My_C_Codes.git
cd My_C_Codes
```

### Compile a Program

Make sure you have a C compiler such as **GCC** installed.

```bash
gcc filename.c -o program
```

### Run the Program

**Linux / macOS:**

```bash
./program
```

**Windows:**

```bash
program.exe
```

You can also open the files directly in **VS Code** or another C-compatible IDE and run them from there.
